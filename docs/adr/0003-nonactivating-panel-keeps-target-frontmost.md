# パネルは自アプリをアクティブにしない

履歴のパネルは `.nonactivatingPanel` の NSPanel で出し、表示時に `NSApp.activate` を呼ばない。貼り先のアプリが前面のままになるので、貼り付け時にアプリを切り替える必要が無く、macOS 14 以降で保証の無い協調アクティベーションに頼らずに済む。文字入力のフォーカスは `canBecomeKey` を true にして得る。

## Consequences

- 設定ウィンドウなどで自アプリがアクティブなときだけ、貼り先の再アクティブ化（タイムアウト付き）が走る
- パネルは `resignKey` で閉じる（クリック外・⌘Tab）
