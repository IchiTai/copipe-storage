# クリップは全形式をそのまま保存し、正規化しない

標準の履歴から貼ると書式が失われるのがこのアプリを作る動機なので、取り込み時にクリップボードの各形式（種類とバイト列）を加工せずそのまま保存し、貼り付け時に全形式を書き戻す。本文＋添付に正規化する設計は、保存できない形式が出た時点で書式を失うため採らない。

## Consequences

- 重複の判定は全形式の一致で行う。同じ文字でも書式の有無が違えば別のクリップになる
- 保存サイズは大きくなる。件数上限と 1 クリップの大きさ上限で抑える
- 未知の形式も失われない代わり、形式ごとの表示はできない（表示は種類＝文字・画像・ファイルの 3 分類で行う）
