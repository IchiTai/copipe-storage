# クリップの正本は manifest で、索引はキャッシュ

履歴の保存は `clips/<id>/manifest.json` を正本とし、`index.json` は並び順と最終使用時刻のキャッシュとして扱う。起動時は `clips/` を走査して manifest が読めるディレクトリをすべて採用し、索引に無いものも取り込む。索引は 250 ms 遅延で書くため、保存前に終了（SIGTERM・クラッシュ・強制終了）したクリップを索引基準で「孤児」として消してはいけない。

## Considered Options

- 索引を正本にして、無いディレクトリを孤児として削除する: 遅延保存と終了のタイミングで完成したクリップを失う。読み込みに失敗した状態で索引を書くと履歴全体を失う
- 変更のたびに索引を同期で書く: 3000 件分の JSON を毎回書き直すことになる

## Consequences

- manifest が読めるディレクトリは版が新しくても削除しない。削除するのは manifest 不在か形式ファイル欠落のものだけ
- `load()` は throw しない。索引の退避に失敗しても manifest から復元して先へ進む
- `load()` 完了前は索引を書かない
