# コピペストレージ 仕様（2026-10-16 時点）

macOS のクリップボード履歴を取り込み、ショートカットから書式を保ったまま貼り付ける常駐アプリの仕様。用語は [CONTEXT.md](../CONTEXT.md)、構成は [architecture.md](architecture.md)、設計の決定は [adr/](adr/) にある。この文書は実装されている振る舞いを正として書く。

## 1. 目的と範囲

- macOS 標準の履歴に無い 2 点を解く: 呼び出すショートカットがあること、履歴から貼っても書式が失われないこと
- 対応 OS: macOS 15 以上（動作確認は macOS 26.7）。個人用で配布は未定。サンドボックス無し
- 表示言語: 日本語と英語（OS の言語に従う）

## 2. 取り込み

| 項目 | 仕様 |
|---|---|
| 対象 | 文字（書式付きを含む）、画像、ファイル参照。元アプリが載せた**全形式**（種類とバイト列）をそのまま保存する |
| 検知 | 0.5 秒ごとに `changeCount` を確認し、変わっていたら読む。パネルを呼び出す瞬間にも読む |
| 除外 | `org.nspasteboard.ConcealedType`（秘匿）、`TransientType`（一時）、`AutoGeneratedType`（自動生成）と、同じ意味の既存の印（1Password、Typinator、TypeIt4Me など）が付いた内容は取り込まない。旧式名が動的 UTI（`dyn.*`）で現れる場合も元の名前に戻して判定する |
| 自分の書き込み | 貼り付け・コピーで自分が載せた内容は取り込まない（`changeCount` の記録と自前の印の両方で判定）。貼ったクリップは明示的に先頭へ移す |
| 重複 | 既存のクリップと全形式（印などのメタデータを除く）が一致したら新しいクリップにせず、既存のクリップを先頭へ移す。同じ文字でも書式の有無が違えば別のクリップ |
| 上限 | 件数上限は既定 1000（設定で 100〜3000）。超えた分は**最後に使ったのが古い順**に消える。1 クリップの大きさ上限は 50 MB（固定）で、超えた内容は通知なしで取り込まない |
| 元アプリ | `org.nspasteboard.source` があればそれ、無ければ取り込み時に最前面だったアプリのバンドル ID |
| 読めない形式 | ある形式のデータが取れなくても `changeCount` が同じなら、その形式だけ飛ばして残りを取り込む。所有者が変わっていたら読み直す |
| 読み取りの拒否 | macOS がクリップボードの読み取りを拒否している（`alwaysDeny`）か、読み取りが 3 回続けて失敗したら、案内の小窓を出す |

## 3. 呼び出しとパネル

- 呼び出し: **⌥C**（設定で変更可）か、メニューバーのアイコンの左クリック。もう一度押すと閉じる
- 位置: マウスカーソルがある画面の中央。幅 520 × 高さ 440
- パネルは自アプリをアクティブにしない。貼り先は前面のまま（docs/adr/0003）
- 表示前に取り込みを 1 回実行し、直前のコピーが先頭に来てから先頭を選んだ状態で開く
- 絞り込み欄に文字を打つと、その場で履歴を狭める（プレビューとファイル名に対する大文字小文字を区別しない部分一致）。閉じると絞り込みは消える
- 行の情報: プレビュー（文字は先頭 2 行、画像はサムネイル＋文字があればその文字、無ければ「画像 幅 × 高さ」、ファイル参照はファイル名の列挙）、元アプリのアイコン、時刻（「たった今」「n 分前」「HH:mm」「昨日 HH:mm」「M/d HH:mm」）、上から 9 件には ⌘1〜⌘9 の印、各行に「コピー」ボタン
- 閉じる条件: Esc、⌥C、パネル外のクリック、他のウィンドウが key になったとき、クリップを選んだとき

キー操作:

| キー | 動作 |
|---|---|
| ↑ ↓ | 選択を移す |
| Enter / クリック | 元の書式で貼り付け |
| ⇧Enter / ⇧クリック | 書式なし貼り付け |
| ⌘Enter / ⌘クリック / コピーボタン | クリップボードに載せるだけ（貼らない） |
| ⌘1〜⌘9 | 見えている並びの上から n 件目を元の書式で貼り付け |
| ⌘⌫ | 選択中のクリップを削除 |
| Esc | 閉じる |
| 文字入力 | 絞り込み。日本語入力の変換中は Return と ↑↓ を IME に渡す |
| ⌘V / ⌘A / ⌘X / ⌘C / ⌘Z | 絞り込み欄の編集（編集メニュー経由） |

## 4. 貼り付け

| 操作 | クリップボードに載せるもの | その後 |
|---|---|---|
| 貼り付け | 保存した全形式（＋自前の印） | 貼り先に ⌘V を送る |
| 書式なし貼り付け | 文字（`public.utf8-plain-text`）だけ。無ければ RTF/HTML から取り出した文字。文字が無いクリップは全形式 | 貼り先に ⌘V を送る |
| コピー | 保存した全形式（＋自前の印） | 何もしない |

- 貼り先は、呼び出しの直前に最前面だったアプリ
- 貼り付けの権限が無いときは載せるだけにして案内を出す（「⌘V で貼り付けてください」＋「システム設定を開く」）
- 自アプリがアクティブなとき（設定ウィンドウを開いているなど）だけ、貼り先を再びアクティブにしてから送る。切り替えられないときや貼り先が終了していたときは載せるだけにして通知を出す
- クリップのデータが読めないときは履歴から取り除き、通知を出す
- 貼ったクリップは履歴の先頭へ移る

## 5. 設定とメニュー

- 設定ウィンドウ（右クリックメニューか歯車 →「設定…」、⌘,）: 呼び出しのショートカット（記録欄）、ログイン時に起動（既定オフ。アプリを「アプリケーション」フォルダに置いてからオンにする）、履歴の件数上限（100〜3000、100 刻み）。「このアプリについて」に版と使用ライブラリ（KeyboardShortcuts、MIT）の表記
- メニュー（メニューバーのアイコンの右クリック、またはパネルの歯車）: 設定… / 履歴をすべて消去…（確認ダイアログ付き）/ コピペストレージを終了
- メインメニュー: メニューバーには出さないが、編集メニュー（取り消す・やり直す・カット・コピー・ペースト・すべてを選択）を持つ。文字欄のキー操作のため
- 二重起動: 同じアプリが既に動いていれば「すでに起動しています」を出して終了する

## 6. 案内の小窓

| 種類 | 出る条件 | ボタン | 消え方 |
|---|---|---|---|
| 貼り付けの権限がありません | 権限が無いまま貼り付けを選んだ | 閉じる / システム設定を開く | 手動（パネルを再表示しても閉じる） |
| クリップボードに載せました | 貼り先に切り替えられない・貼り先が終了していた | 閉じる | 20 秒で自動 |
| クリップボードを読み取れません | 読み取りの拒否を検知した | 閉じる / システム設定を開く | 手動 |
| 貼り付けできませんでした | クリップのデータが読めなかった | 閉じる | 20 秒で自動 |

小窓は key にならず、全 Space に出る。キー入力は貼り先に届いたままなので、ボタンはマウスで押す。

## 7. 保存

```
~/Library/Application Support/jp.ichitai.copipestorage/
  index.json                 並び順と最終使用時刻のキャッシュ
  clips/<uuid>/manifest.json クリップの正本（種類・プレビュー・形式の一覧 など）
  clips/<uuid>/<item>-<rep>.bin 形式ごとの生バイト
  clips/<uuid>/thumbnail.png 画像の縮小版（長辺 256 px）
```

- manifest が正本（docs/adr/0004）。起動時は `clips/` を走査し、manifest が読めるディレクトリをすべて採用する（索引に無くても）。索引は並びと最終使用時刻にだけ使い、壊れていれば退避して作り直す
- 削除するのは manifest が無いディレクトリと、形式ファイルが欠けたディレクトリだけ。読めない manifest や新しい版の manifest は残す
- クリップは一時ディレクトリに全部書いてから改名するので、途中で止まっても完成したものだけが見える。索引は変更から 250 ms 後にまとめて書き、終了時にも書く
- 暗号化はしない。壊れた索引は `index.json.corrupt-<日時>` に退避する

## 8. 権限

- **貼り付けの権限**: ⌘V を送るためにシステム設定 >「プライバシーとセキュリティ」>「アクセシビリティ」で許可が要る。許可したあとはアプリの再起動が必要なことがある。署名が同じなら（自己署名の identity）再ビルドしても権限は維持される
- **読み取りの許可**: macOS 15.4 以降の仕組み。macOS 26.7 時点では既定で無効。拒否を検知したときだけ案内する
- **ログイン項目**: `SMAppService` で登録する。アプリの置き場所を変えると登録が外れる

## 8b. アンインストールで残るもの

アプリ本体（`Copipe Storage.app`）は読み取り専用で、データは外に置くため、アプリを削除しても次の 3 つは残る。

| 残るもの | 場所 | 消し方 |
|---|---|---|
| 履歴 | `~/Library/Application Support/jp.ichitai.copipestorage/` | フォルダごと削除（または削除前にメニューの「履歴をすべて消去…」） |
| 設定（件数上限、ショートカット） | `~/Library/Preferences/jp.ichitai.copipestorage.plist` | ファイルを削除 |
| ログイン項目・貼り付けの権限 | システム設定（一般 > ログイン項目、プライバシーとセキュリティ > アクセシビリティ） | 削除前に設定で「ログイン時に起動」をオフ。権限の一覧からは手で外す |

## 9. 既知の制限

- 50 MB を超える内容は通知なしで取り込まない
- ファイル参照のクリップは、貼る時点でファイルが無くてもそのまま貼る
- ⌘V の送出はキーコード 9（US/JIS 配列の V）固定。Dvorak などでは V にならない
- 元アプリが遅延提供するデータ（巨大なデータや Universal Clipboard）は、取り込み時に相手の応答を待つ
- プレビューは先頭 8 KB から作る。RTF/HTML しか無いクリップは 256 KB 以下のときだけプレビューを作る
- 英語配列では ⌥C で「ç」を打てなくなる（ショートカットは変更可）

## 10. 技術構成

- Swift Package（`Package.swift` のみ。Xcode プロジェクト無し）。`CopipeCore`（取り込み・保存・貼り付けの論理、Swift Testing でテスト）と `CopipeStorage`（AppKit + SwiftUI の画面）。依存は KeyboardShortcuts だけ
- ビルドは `make app`（リリース）/ `make app-debug`（検証用 URL 付き）。`swift build --build-system swiftbuild` 固定（docs/adr/0002）
- 署名は自己署名の `Copipe Storage Dev`、Hardened Runtime 有効
- 検証用 URL（デバッグ構成のみ）: `copipestorage://panel/show`、`debug/key`、`debug/filter`、`debug/select`、`debug/status`、`debug/settings`、`debug/guide`、`debug/snapshot`

## 11. 計画からの変更履歴

計画（2026-10-15 承認）からの主な変更。理由は括弧内。

- 「載せるだけ」の修飾キーを ⌥ から ⌘ に（ユーザー希望）。⌥⌘数字は廃止。各行に「コピー」ボタンを追加（ユーザー希望。枠付き・⌘n の右・列幅固定）
- 既定のショートカットを ⇧⌘V から ⌥C に（ユーザー希望、2026-10-16）
- 削除キーを Delete から ⌘⌫ に（絞り込み欄の文字削除と衝突するため）
- 保存を「索引が正本」から「manifest が正本」に（終了のタイミングで完成したクリップを失わないため。レビュー指摘）
- 読み込み失敗時に throw せず復元へ進む。読み込み完了前は索引を書かない（履歴全消失の防止。レビュー指摘）
- 二重起動の防止を追加（同じ保存先を取り合うため。レビュー指摘）
- 呼び出し時に取り込みを待ってから表示（直前のコピーが未選択になるため。レビュー指摘）
- 編集メニューを設置（文字欄で ⌘V などが効かなかったため。レビュー指摘）
- 案内の小窓からキー割り当てを外す（key にならないため。レビュー指摘）
- 文字と画像の両形式を持つクリップは、サムネイルと文字の両方を出す（表計算のセル範囲が検索できなかったため。レビュー指摘）
- 書式なし貼り付けで RTF/HTML から文字を取り出す。文字が無いクリップは元の形式で貼る（レビュー指摘）
- 貼り付けの権限判定に Accessibility の付与も含める（システム設定の同じ欄に両者が混在するため）
- 権限の案内は自動で閉じず、全 Space に出す（別の Space で見失ったため）
- ファイル参照のプレビューは「a, b」の列挙（計画の「ほか n 件」より分かりやすいため）
- 検証用 URL を増やした（filter / select / key / status / settings / guide）
